01 · 判断校验

大方向正确，产品语言需要更精确

“主入口”不等于“唯一 UI”；“支持 OAuth”不等于最终用户身份到达数据源；“有 MCP”也不等于工具已经安全。以下置信度是研究判断，不是统计概率。

强成立
90%研究置信度

Genie One 一类 Agent 对话会成为主任务入口

多个厂商同时把问数、报告、应用、任务和工具收敛到统一自然语言入口。结构化 UI 仍负责复杂编辑、批量运营、审批和异常处理。

成立
85%研究置信度

用户会主要用自然语言启动任务

自然语言适合表达目标、跨产品路由和探索式追问；生产流程仍需沉淀为稳定、版本化、参数化的对象与策略。

部分成立
60%研究置信度

其他能力都会包在 CLI / MCP 中

CLI 是自动化外壳，MCP 是 Agent 工具适配层。API、对象模型、Catalog、策略与执行引擎才应是系统真相源。

强成立
95%必要性置信度

数据治理和授权是关键

它们是入场券而非充分条件。最终壁垒还包括业务语义、工具/动作安全、正确性评测、Trace/版本与成本可靠性。

核心改写人机交互正在从菜单驱动转为意图驱动；产品竞争正在从“谁能生成回答”，转向“谁能以正确身份，在正确语义和策略下，调用正确工具完成任务，并给出可验证、可审计、可恢复的结果”。

07 · 建议路线

先证明信任链，再逐步开放自治

这是能力依赖顺序，不是未经团队容量验证的交付承诺。每一阶段都由可执行 Gate 决定是否晋级。

H0

统一契约与身份

证明一个人、一个资源、一个任务跨产品不断链。

  • Canonical IDs
  • API 权威契约
  • 短期 OBO / Agent identity
  • 逐工具 deny-by-default
Gate：UI/API/CLI/MCP/嵌入的权限正负例一致，一个 trace 关联全链。
H1

可信只读任务

先在一个高价值场景把答案与结果工件做深。

  • 共享指标/语义版本
  • SQL/结果等价
  • 权限负例与成本基线
  • 可保存 Report/Dashboard
Gate：无未裁决高风险错误；多入口结果、Provenance 和 ACL 等价。
H2

外部 Agent 与受控动作

让第三方 Agent 进入同一策略面，写动作进入确定状态机。

  • 安全 Tool Registry
  • DB AST/预算/取消
  • 草案/审批/幂等
  • 后置验证与补偿
Gate：不以模型自报成功验收；每个动作读取权威后置状态。
H3

策略限定自治

从逐步批准升级到目标、工具、预算与风险范围内自治。

  • 计划与活动记录
  • Policy simulation
  • Canary / Kill switch
  • 完整 delegation chain
Gate：H0–H2 连续满足安全、正确性和恢复 Oracle 后才能晋级。
厂商路线钻取

当前交付与下一攻击面

“当前”来自官方资料；“下一步”是由连续发布轨迹形成的推断，不是厂商内部承诺。

最终产品判断

不要追赶一个页面，要建立一条信任链。

Databricks 和 Snowflake 当前领先的不是“更会聊天”，而是更接近把数据、语义、身份、工具和 Agent 保证体系变成同一个产品闭环。华为追赶最快的路径，是把已经存在的 DataArts、AgentArts 和数据库能力通过同一身份、对象、策略、任务和证据链真正连起来。

入口统一但可替换：自有页面与第三方 Agent 使用同一能力。
控制面身份、语义、工具策略、任务和 Trace 是共同真相源。
推进方式联合控制面优先；只有 Gate 证伪后，才决定哪些能力必须新建。
